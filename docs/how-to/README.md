# How-to guides

Recipes for specific operator tasks. Each guide assumes you already
know the package shape (read the [tutorials](../tutorials/) first if
you don't).

- [Install external ground-truth datasets](install-external-datasets.md) —
  use `pdf2md datasets install` to fetch third-party LaTeX corpora.
- [Update factory-shipped calibration priors](update-factory-priors.md) —
  refresh the priors that ship with the package.
- [Troubleshoot local runs](troubleshoot-local-runs.md) — common
  errors (CUDA, paddleocr, LaTeX toolchain) and the fix for each.
