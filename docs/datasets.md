# External ground-truth datasets

`pdf2md` ships with a controlled synthetic LaTeX corpus under
[`groundtruth/corpus/latex/`](../groundtruth/corpus/latex/). Those
fixtures are generated by
`generate_latex_docling_groundtruth.py` and test specific LaTeX
features in isolation.

This page documents the **opt-in** workflow for downloading
**third-party** LaTeX source corpora into `groundtruth/external/` so
they can later be compiled and used as additional benchmark targets.
Downloads happen only when the user explicitly invokes the CLI — they
are never performed during package installation.

## Provenance and licences

| Dataset           | Source                                                   | Licence                                       | Purpose                                                          |
|-------------------|----------------------------------------------------------|-----------------------------------------------|------------------------------------------------------------------|
| `tlc3-examples`   | [`FrankMittelbach/tlc3-examples`](https://github.com/FrankMittelbach/tlc3-examples) | LPPL-1.3c (with README-noted exceptions)      | Feature-level variety across classes, floats, tables, math, bib |
| `latex-cookbook`  | [`alexpovel/latex-cookbook`](https://github.com/alexpovel/latex-cookbook)            | MIT                                           | Realistic multi-file project — end-to-end stress test            |
| `arxiv-curated`   | (placeholder)                                            | varies per paper                              | Reserved for a curated arXiv set; **not downloadable** here     |

These external corpora are **not** vendored into the repository. The
user must download them with the CLI below; nothing is fetched until
they ask for it.

## Layout after installation

```text
groundtruth/
├── corpus/
│   └── latex/                          ← synthetic fixtures (untouched)
├── external/
│   ├── tlc3-examples/
│   │   ├── upstream/
│   │   │   ├── NORMAL/
│   │   │   ├── SPECIAL/
│   │   │   ├── SUPPORT/
│   │   │   ├── README.md
│   │   │   └── build.lua
│   │   ├── dataset.json
│   │   └── manifest.jsonl
│   └── latex-cookbook/
│       ├── upstream/
│       │   ├── cookbook.tex
│       │   └── …
│       ├── dataset.json
│       └── manifest.jsonl
└── manifest/
    └── external_datasets.json          ← global index of installed externals
```

`BOOK-PDFS/` from the upstream `tlc3-examples` clone is excluded by the
keep/exclude rules in the registry — only the LaTeX source trees plus
asset files under `SUPPORT/` are kept.

## CLI usage

```bash
# Show all registered datasets, their aliases, licence and status.
conda run -n pdf2md pdf2md datasets list

# Show what installation would do (no files created).
conda run -n pdf2md pdf2md datasets install tlc3 --dry-run
conda run -n pdf2md pdf2md datasets install latex-cookbook --dry-run

# Download + position + generate manifests.
conda run -n pdf2md pdf2md datasets install tlc3
conda run -n pdf2md pdf2md datasets install latex-cookbook

# Install everything available in one go (skips arxiv-curated).
conda run -n pdf2md pdf2md datasets install all

# Report what is installed / missing / not_installed.
conda run -n pdf2md pdf2md datasets status

# Regenerate manifests from an existing local install (no network).
conda run -n pdf2md pdf2md datasets install tlc3 --manifest-only

# Force overwrite of an existing install.
conda run -n pdf2md pdf2md datasets install tlc3 --force
```

### Useful options

| Option              | Meaning                                                                                  |
|---------------------|------------------------------------------------------------------------------------------|
| `--output PATH`     | Override the install root (default: `groundtruth/external`).                             |
| `--ref REF`         | Override the git ref (branch or commit SHA) — default comes from the registry entry.    |
| `--force`           | Delete an existing dataset directory before re-cloning.                                  |
| `--dry-run`         | Print the planned action with no filesystem changes.                                     |
| `--manifest-only`   | Regenerate `dataset.json` + `manifest.jsonl` from existing local data; skip git clone.  |
| `--compile`         | Reserved; prints "Not implemented in Plan 17. See Plan 18." and exits cleanly.          |
| `--limit`           | Reserved (same as above).                                                                |
| `--engine`          | Reserved (same as above).                                                                |

The `arxiv-curated` entry is a registry placeholder. Attempting to
install it prints a clear message; no clone is attempted.

## What the manifests look like

`groundtruth/external/<dataset>/dataset.json`:

```json
{
  "schema_name": "pdf2md.ExternalDatasetMeta",
  "schema_version": 1,
  "id": "tlc3-examples",
  "source_url": "https://github.com/FrankMittelbach/tlc3-examples.git",
  "ref": "main",
  "resolved_commit": "deadbeef...",
  "licence": "LPPL-1.3c (with README-noted exceptions)",
  "installed_at": "2026-05-24T22:00:00Z",
  "upstream_path": "groundtruth/external/tlc3-examples/upstream",
  "root_file_count": 142,
  "compile_status": "not_run"
}
```

`groundtruth/external/<dataset>/manifest.jsonl` — one entry per root
LaTeX file:

```json
{"id":"tlc3-NORMAL-1-3-1","dataset":"tlc3-examples","root_file":"upstream/NORMAL/1-3-1.ltx","source_type":"latex","has_media":false,"compile_status":"not_run","features":[]}
```

`groundtruth/manifest/external_datasets.json` — global index summarising
every installed dataset:

```json
{
  "schema_name": "pdf2md.ExternalDatasetsIndex",
  "schema_version": 1,
  "entries": [
    {
      "id": "tlc3-examples",
      "path": "groundtruth/external/tlc3-examples",
      "source_url": "https://github.com/FrankMittelbach/tlc3-examples.git",
      "ref": "main",
      "resolved_commit": "deadbeef...",
      "status": "installed",
      "compile_status": "not_run"
    }
  ]
}
```

## Compilation is a separate plan

`compile_status` stays at `not_run` after `datasets install` —
**this plan does not compile anything**. Plan 18 (Compilation &
Ingestion) will:

1. Compile TLC3 candidates with `pdflatex`.
2. Compile `latex-cookbook` with `lualatex` (requires a fuller TeX
   distribution).
3. Record per-document compilation logs and classify failures.
4. Produce a successful-subset manifest.
5. Optionally run backend extraction on the compiled PDFs.

External datasets remain **third-party benchmark sources**. They are
**not** automatically canonical approved ground truth fixtures. The
canonical synthetic corpus under `groundtruth/corpus/latex/` is
unaffected by anything in this workflow.

## Re-generating manifests without re-cloning

If you tweak the registry's `root_globs` or `keep_paths` and want to
refresh the manifests for an existing local install:

```bash
conda run -n pdf2md pdf2md datasets install tlc3 --manifest-only
```

This skips the git clone and re-walks the existing `upstream/` tree.

## Requirements

- `git` on `$PATH` (for the actual clone — checked via
  `shutil.which("git")`; missing → clear error).
- Network access (only at install time; tests use local fake repos).
- Disk: a few hundred megabytes for both available datasets combined.
