# Tutorials

Tutorials teach the package by example. Follow them in order — each one
builds on the previous tutorial's environment.

| # | Tutorial | What you build |
|---|----------|----------------|
| 01 | [Set up backends](01-setup-backends.md) | A working `pdf2md.backends.toml` and at least one backend env. |
| 02 | [Convert your first PDF](02-first-conversion.md) | A single-PDF run producing Docling JSON + Markdown + RAG chunks. |
| 03 | [Calibrate priors on the corpus](03-calibrate-priors-on-corpus.md) | Per-backend calibration priors derived from ground truth. |
| 04 | [Batch processing and multi-backend](04-batch-processing.md) | A corpus-mode run with calibrated consensus across backends. |

If you only need a quick recipe (not a guided walkthrough), see
[`../how-to/`](../how-to/) instead.
